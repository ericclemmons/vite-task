# node_modules_bin_target_changed

A pnpm shim is fingerprinted by the package file it runs, so upgrading the package is a cache miss, even when the old version's files are still in `node_modules/.pnpm`.

## `vtt mkdir -p node_modules/.bin`

```
```

## `vtt cp shim-1.0.0.sh node_modules/.bin/tool`

```
```

## `vt run read-shim`

cache miss

```
$ vtt print-file node_modules/.bin/tool
#!/bin/sh
export NODE_PATH="$basedir_abs/../.pnpm/tool@1.0.0/node_modules"
exec node "$basedir_abs/../.pnpm/tool@1.0.0/node_modules/tool/bin/tool" "$@"
# cmd-shim-target=../.pnpm/tool@1.0.0/node_modules/tool/bin/tool
```

## `vtt cp shim-2.0.0.sh node_modules/.bin/tool`

upgrade the package, which rewrites the shim

